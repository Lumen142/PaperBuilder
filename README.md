# PaperBuilder V1.0.0

This software is a simple tool that makes setting up a Minecraft server easy.


## Usage/Examples

`node main.js` -->> 
You can easily launch the application and set up your server in a very simple way by answering the questions that appear.

  
## FAQ

#### Is it compatible with Windows?

Yes. It was improved with version V1.0.0 to support Windows devices.

#### Is it compatible with Linux distributions?

Version V0.0.2 is a very early developer release tested on Ubuntu and Debian. V1.0.0 was only tested on Windows devices.
